Fundamentos & Arquitetura Oracle

Instance · Database · SGA · PGA · Processos · Arquivos
Básico
Conceitos Essenciais
ItemDescrição
DatabaseConjunto físico de arquivos: datafiles, control files, redo logs, tempfiles
InstanceMemória + processos que acessam o database
SGAMemória compartilhada: buffer cache, shared pool, redo log buffer, large/java/streams pool
PGAMemória privada de cada processo servidor
CDB/PDBArquitetura multitenant: Container Database e Pluggable Databases
Data DictionaryMetadados do banco: USER_, ALL_, DBA_, V$, GV$
SCNSystem Change Number; marca lógica de consistência
CheckpointSincroniza buffers sujos para disco e atualiza headers/controlfile
Arquivos Físicos
ItemDescrição
DatafilesArmazenam segmentos: tabelas, índices, undo, LOBs
Control filesEstrutura crítica com metadados, SCN, backups e redo history
Online redo logsRegistram mudanças para recuperação de instância
Archived redo logsCópias dos redos para recuperação e Data Guard
TempfilesUsados por tablespace temporária em sort/hash/temp
Password fileAutenticação administrativa remota SYSDBA/SYSOPER
SPFILE/PFILEParâmetros de inicialização da instância
Processos Background
ItemDescrição
PMONLimpa sessões mortas e registra serviço no listener
SMONInstance recovery e limpeza de segmentos temporários
DBWnGrava dirty buffers para datafiles
LGWRGrava redo buffer nos online redo logs
CKPTSinaliza checkpoints e atualiza headers
ARCnArquiva online redo logs
MMON/MMNLAWR, snapshots e métricas
CJQ0/JnnnScheduler jobs

Criar e expandir tablespace
oracle@dbserver
SQL> create tablespace app_data datafile '/u02/oradata/ORCL/app_data01.dbf' size 10G autoextend on next 1G maxsize 50G;

Backup & Recovery com RMAN

Backupset · Image Copy · Archivelog · Restore · Recover
Intermediário
Estratégia RMAN
ItemDescrição
Full backupBackup completo do banco
Incremental level 0Base para incrementais
Incremental level 1Mudanças desde level 0 ou último level 1
Archivelog backupNecessário para point-in-time recovery
Controlfile autobackupCrítico para recuperação de desastre
Retention policyRecovery window ou redundancy
CrosscheckSincroniza catálogo RMAN com arquivos físicos
Backup completo
oracle@dbserver
$ rman target /
SQL> configure controlfile autobackup on;
SQL> configure retention policy to recovery window of 7 days;
SQL> backup as compressed backupset database plus archivelog;
SQL> delete noprompt obsolete;
Restore e recover básico
oracle@dbserver
SQL> startup mount;
SQL> restore database;
SQL> recover database;
SQL> alter database open;
PITR — visão geral
oracle@dbserver
SQL> run {
$ set until time "to_date('2026-06-11 10:00:00','yyyy-mm-dd hh24:mi:ss')";
$ restore database;
$ recover database;
$ alter database open resetlogs;
SQL> }
