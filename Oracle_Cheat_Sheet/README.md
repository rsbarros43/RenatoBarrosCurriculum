📖 Sobre o Projeto

O Oracle Database Cheat Sheet & Interactive DBA Lab foi desenvolvido com o objetivo de reunir em um único ambiente os principais conceitos, comandos, procedimentos e boas práticas utilizados por Administradores de Banco de Dados Oracle (DBAs).

O projeto funciona como:

* Cheat Sheet Oracle Database
* Guia de Estudos
* Material de Treinamento
* Laboratório Interativo
* Portfólio Profissional
* Apoio para Certificações Oracle

⸻

🎯 Objetivos

Este projeto foi criado para auxiliar profissionais e estudantes a aprenderem Oracle Database de forma prática e organizada.

Principais objetivos:

* Aprender Oracle Database na prática
* Revisar conceitos importantes
* Executar exercícios simulados
* Preparar-se para entrevistas técnicas
* Apoiar estudos para certificações Oracle
* Demonstrar conhecimento técnico através de um portfólio profissional

🧪 Simulador Oracle

O projeto possui um laboratório interativo integrado ao navegador.

Exemplos de comandos suportados:

help
show pdbs
show user
show parameter
select instance_name,status from v$instance;
select name,open_mode
from v$database;
select username
from dba_users;
select tablespace_name
from dba_tablespaces;
startup;
shutdown immediate;
lsnrctl status;
rman target /;

Observação

O simulador possui finalidade educacional.

Os comandos são simulados para fins de aprendizado e não executam operações em um banco Oracle real.
