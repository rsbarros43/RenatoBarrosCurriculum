# Contribuindo

1. Abra uma issue descrevendo a correção ou melhoria.
2. Crie uma branch específica.
3. Preserve a identidade visual, a autoria e o caráter educacional.
4. Não inclua documentação proprietária, credenciais, dados reais ou conteúdo confidencial.
5. Valide o funcionamento em navegador desktop e mobile.
6. Envie um pull request com resumo das mudanças e evidências de teste.
