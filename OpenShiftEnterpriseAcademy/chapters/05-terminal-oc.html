Capítulo 05 — Simulador de terminal oc

Este capítulo concentra os comandos essenciais para administrar um ambiente OpenShift. Use os botões abaixo para praticar comandos como se estivesse em um terminal real.

Comandos essenciais

oc get projects: lista namespaces/projetos disponíveis.
oc get pods: lista containers em execução no projeto atual.
oc get nodes: mostra os nós do cluster.
oc describe node: detalha capacidade, condições e pods do nó.

Resumo rápido dos termos até aqui

Antes de praticar, um resumo dos conceitos vistos nos capítulos anteriores, todos numa mesma frase cada:

Cluster: o conjunto de máquinas administradas pelo Kubernetes como uma coisa só.
Node: uma máquina individual dentro do cluster.
Project/Namespace: o "espaço de trabalho" isolado onde ficam os recursos de uma aplicação.
Pod: a menor unidade executável — um ou mais containers rodando juntos.
Deployment: garante que o número certo de pods esteja sempre rodando.
Service: dá um endereço interno estável para acessar os pods.
Route: expõe o Service para acesso externo, fora do cluster.

Prática guiada

✓ Terminal praticado.
Dica de entrevista: saiba explicar a diferença entre project, namespace, deployment, pod, service e route.
