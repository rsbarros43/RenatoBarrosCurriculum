Capítulo 03 — Instalação do CRC / OpenShift Local

O CRC cria uma VM local contendo um cluster OpenShift pronto para estudos. A instalação real envolve baixar o binário, extrair, configurar o ambiente e iniciar o cluster com o pull secret.

Download oficial: o binário do CRC e o pull secret são obtidos na mesma página, direto no portal da Red Hat: console.redhat.com/openshift/create/local. É necessária uma conta gratuita Red Hat Developer para acessar.

Fluxo de instalação (visão geral)

1. Baixar CRC: na página oficial acima, escolha o pacote do seu sistema operacional (Linux, macOS ou Windows) e baixe também o pull secret.
2. Instalar binário: no Linux, extraia o `.tar.xz` e mova o executável crc para um diretório no PATH (ex: /usr/local/bin). No macOS e Windows, execute o instalador guiado (`.pkg` ou `.msi`) — ele já cuida do PATH automaticamente.
3. Executar setup: rode crc setup. No Linux, esse comando prepara libvirt, NetworkManager e as dependências de rede. No macOS ele configura o HyperKit/vfkit, e no Windows o Hyper-V.
4. Start: rode crc start -p pull-secret.txt para iniciar o cluster. A primeira inicialização baixa a imagem do cluster e pode levar de 5 a 15 minutos.
5. Configurar o CLI: rode eval $(crc oc-env) para adicionar o oc ao PATH da sessão atual automaticamente.
Diferença por sistema operacional: os requisitos de hardware (CPU, RAM, disco) são os mesmos em qualquer SO. O que muda é apenas a camada de virtualização por baixo dos panos — libvirt/KVM no Linux, HyperKit/vfkit no macOS, Hyper-V no Windows — e o formato do instalador.

Runbook principal

crc setup crc start --pull-secret-file ~/Downloads/pull-secret.txt crc status
