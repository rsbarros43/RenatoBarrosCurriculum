# OpenShift Enterprise Academy v2.3.0

Projeto interativo com visual Red Hat para estudo de OpenShift, Kubernetes, OpenShift Local, `oc`, deploy de aplicação Flask e CI/CD com Tekton.

## Destaque desta versão

A v2.3.0 conclui a trilha completa: capítulos 11 a 14, quiz funcional com correção automática e certificado de conclusão gerado dinamicamente.

## Trilha completa (14 capítulos)

1. Introdução
2. Pré-requisitos
3. Instalação do CRC
4. Primeiro login
5. Simulador de terminal `oc`
6. Gerenciando projetos
7. Explorando o cluster
8. Deploy da aplicação Flask
9. Pipelines Tekton
10. Triggers e GitHub Webhook
11. Projeto Final — Pipeline CI/CD completa
12. Troubleshooting
13. Quiz (10 perguntas, aprovação com 70%+)
14. Certificado de conclusão (gerado automaticamente após aprovação no quiz)

## Como abrir

Abra o arquivo `index.html` no navegador.

## Estrutura

- `index.html` - Dashboard
- `chapters/` - Capítulos do treinamento
- `css/` - Estilos do layout
- `js/` - Navegação, progresso, terminal, simulador, quiz e certificado
- `docs/` - Documentação complementar
- `labs/` - Espaço reservado para laboratórios práticos fora do navegador

## Quiz e certificado

O quiz (capítulo 13) tem 10 perguntas de múltipla escolha cobrindo todo o conteúdo do curso. Ao atingir 70% ou mais de acerto, o módulo é marcado como concluído automaticamente e o certificado (capítulo 14) é liberado, com nome do aluno, data de emissão e código de verificação únicos. O certificado pode ser impresso ou salvo como PDF diretamente do navegador.
