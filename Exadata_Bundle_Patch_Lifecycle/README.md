Exadata Bundle Patch Lifecycle Command Center

Interactive Command Center desenvolvido para profissionais Oracle Exadata, DBAs, Database Engineers, Cloud Engineers e equipes de infraestrutura que desejam aprender, praticar e simular o ciclo completo de atualização de ambientes Oracle Exadata.

⸻

Visão Geral

O Exadata Bundle Patch Lifecycle Command Center foi criado para reproduzir de forma visual, interativa e educacional uma jornada completa de atualização de uma plataforma Oracle Exadata.

O projeto simula um cenário real de atualização crítica envolvendo:

* Assessment Inicial
* ExaChk
* Backup e Estratégia de Rollback
* Upgrade Oracle Linux 7 para Oracle Linux 8
* Grid Infrastructure Release Update
* Oracle Database Release Update 19.31
* Datapatch
* PatchMgr
* DCLI
* CellCLI
* Atualização da Malha Infiniband
* Pós-Validação
* Troubleshooting
* Interview Mode
* Certificação Final

⸻

Objetivo do Projeto

Este laboratório foi desenvolvido para permitir que DBAs e equipes de infraestrutura compreendam o fluxo operacional de uma atualização Exadata de forma segura e controlada.

O foco não é apenas a aplicação dos patches, mas também:

* Planejamento da mudança
* Validação de pré-requisitos
* Execução controlada
* Verificação de conformidade
* Health Check
* Performance Validation
* Testes Funcionais
* Go Live
