# Renato Barros Curriculum Web v3.0.3

Currículo web profissional bilíngue, desenvolvido para apresentar experiência, competências, certificações, formação e projetos técnicos de Renato Barros.

## Arquivos

- `index.html` — versão em português
- `index-en.html` — English version
- `CV_Renato_Barros_2026.pdf` — currículo em PDF
- `assets/` — fotografia e currículo visual
- `favicon.svg` — identidade visual da aba
- `robots.txt` — indexação básica
- `site.webmanifest` — metadados para navegador

## Execução local

Abra `index.html` no navegador. Para evitar restrições locais do navegador, também é possível executar:

```bash
python3 -m http.server 8000
```

Acesse `http://localhost:8000`.

## Publicação

O projeto é estático e compatível com GitHub Pages. Antes da publicação definitiva, configure a URL final nos metadados `canonical`, `og:url` e `og:image` quando o endereço do repositório/site estiver definido.
