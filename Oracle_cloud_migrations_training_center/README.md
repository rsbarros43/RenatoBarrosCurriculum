# Oracle Cloud Migrations Interactive Training Center v7

## Ajustes da v7

- Ao clicar em **Tentar novamente**, o sistema limpa as respostas e volta automaticamente para o Módulo 01.
- Mantida a correção final com respostas verdes/vermelhas.
- Certificado ajustado com descrição mais completa.
- Botão iniciar alinhado com a caixa do nome.

## Como usar

1. Extraia o ZIP.
2. Abra `index.html`.
3. Digite o nome.
4. Clique em **Iniciar treinamento**.
5. Responda as perguntas.
6. No final, clique em **Corrigir prova e ver resultado**.
7. Se aprovado com 75% ou mais, emita o certificado.
