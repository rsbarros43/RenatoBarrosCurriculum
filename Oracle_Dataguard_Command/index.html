FUNDAMENTOS DO ORACLE DATA GUARD

O que é Data Guard?

Oracle Data Guard é uma solução de alta disponibilidade, proteção de dados e recuperação de desastres. Ele mantém uma ou mais bases standby sincronizadas com o banco Primary por meio do transporte e aplicação de redo.

Em caso de manutenção planejada, é possível executar um Switchover. Em caso de desastre no Primary, o Standby pode ser promovido por meio de Failover.

O que este lab simula?

Este tutorial guia o aluno pela preparação do Primary, criação do Standby, validação, monitoramento, Broker, Switchover, Failover, FSFO, RAC e troubleshooting.

AVISO TÉCNICO IMPORTANTE

Este material é um laboratório educacional simulado para estudo, treinamento e demonstração técnica de Oracle Data Guard.

Para uso em produção, valide obrigatoriamente os detalhes específicos do ambiente antes de aplicar qualquer configuração.

  • paths de datafiles, FRA, archive logs e Oracle Home;
  • DB_NAME, DB_UNIQUE_NAME, service names, TNS e listener;
  • password file, parâmetros Data Guard e conectividade entre servidores;
  • RAC threads, standby redo logs, ASM/diskgroups e política de backup;
  • modo de proteção, RTO/RPO, Broker, FSFO, Observer e requisitos do cliente.
