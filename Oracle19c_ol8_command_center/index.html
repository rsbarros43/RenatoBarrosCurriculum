Fundamentos

O que será instalado?

Oracle Database 19c single instance no OL8, ORACLE_HOME em /u01, DATA_DIR em /u02/oradata, CDB cdb1 e PDB pdb1.

Atenção

O fluxo exige OL8 com UEK6 e patch level 19.7+ para suporte oficial. Para laboratório, a instalação pode seguir com 19.3 e patch opcional.

OL8 Setup

Configuração do hosts, hostname, preinstall e update.
O botão executar marca cada comando e mostra a saída no terminal fixo.

Manual Setup

Parâmetros de kernel, limits, pacotes, grupos, usuário, SELinux, firewall e scripts.
Use este caminho quando não usar o pacote de pré-instalação.

Installation / Patch

Instalação interativa ou silent do software Oracle 19c.
Inclui root scripts e patch opcional usando OPatch.

Database Creation / Post Installation

Criação do banco com DBCA, listener, oratab, OMF e PDB save state.
Validações finais com SQL*Plus, listener e scripts start/stop.

Health Check Pós-instalação

Objetivo
Executar uma validação final parecida com uma rotina real de DBA: versão, instância, CDB/PDB, listener, patches e estado operacional.
Como usar
Clique em cada botão para enviar a validação ao terminal sticky. O resultado aparece como se o DBA estivesse validando manualmente no servidor.
Health Check completo
Executa as principais validações pós-instalação em sequência.
sqlplus / as sysdba
select banner from v$version;
select instance_name,status from v$instance;
select name,open_mode,cdb from v$database;
show pdbs
archive log list
lsnrctl status
opatch lspatches
